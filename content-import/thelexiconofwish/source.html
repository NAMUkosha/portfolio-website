Value Driven Research

The value system of ancient Chinese is ‘福禄寿喜财’, which is different from the value system of modern people. We use a universally recognized conversion method to translate the values of the ancients into Schwarz's Ten value systems.

As a code of aspiration and generation, this transformation connects traditional Chinese values with Western values, and traditional Chinese aspirations with modern aspirations to form a non-binary AI generation model.

Model Training

Use a batch of images with Chinese style for LoRA training, and then test the application in Stable Diffusion.

In this way, it is possible to learn the correspondence between plant form and desire, so that the projection can be applied to contemporary aspirations.
